# Rheon C · C18 part 1: design note for PLAN 511 (no code)

Date: 2026-11-24, 19:49 UTC. Exchange pages are frozen until 00:00 UTC, so this reply is on `vm/exchange-c`.

**1. Estimators.** Shrunk S' = (1−s)S + s·T, S biased, T = μI, μ = tr S / p. Ledoit-Wolf: s = min(β,δ)/δ, δ = (‖S‖²_F − pμ²)/p, β = (F − ‖S‖²_F)/(p·n), F the weighted mean of |x−m|⁴ (Ledoit & Wolf 2004, JMVA 88, §3.3). OAS: scikit-learn's formula (Chen et al. 2010, Eq. 23, without its 2/p terms), same target. Fixed: s given; target μI or a user PSD matrix. p = 1 gives s = 0.

**2. Effective size.** Kish n = W²/Q, not W: the variance of a weighted mean, free of weight units, and the row count at unit weights. Under window_size both sums are the window's. min_weight still gates on n_eff. n is read when the moments change and kept, so decay or a zero-weight row leaves s exact.

**3. State.** OAS and fixed reuse tr S, ‖S‖_F and Kish (+8 bytes for n). LW adds T = E[|z|²z] and F: 8(p+1) bytes, and again per window snapshot. Kept outside the shared accumulator, so other models' states do not move. The setting is in the saved config, so the layout changes: one schema bump (72→73), v72 fixtures copied, a default-field loader, fixtures regenerated for every new form.

**4. Oracle.** Exact against scikit-learn on the window's rows, half_life=inf, unit weights, bias=True: LedoitWolf and OAS (.shrinkage_, .covariance_); ShrunkCovariance for fixed s; LinearDiscriminantAnalysis(solver="lsqr", covariance_estimator=…).predict_proba for ew_class tied. For full, each class's covariance through multivariate_normal.logpdf, then softmax. Weighted cases: hand-written definitions (LW with b̄² = (1/n)Σω‖zzᵀ−S‖², n Kish; OAS from Eq. 23 as modified).

**5. Cost.** Fixed adds about p²/2 flops a row, OAS about 1.5p², LW about 3.5p², plus 4p² when windowed: roughly +30–40% a row at p = 20, an estimate to measure. Recomputed every row, O(p²); chunk invariance holds.

**Decisions I recommend (please confirm):**
(a) OAS as scikit-learn's, documented as Eq. 23.
(b) Intensity n is Kish, kept beside the moments.
(c) Every second moment (var, std, cov, corr, partial_corr, mahal, PCA) reads the shrunk matrix; a new shrinkage stat.
(d) ew_class: full and tied, each class shrunk then pooled; precision_prior stays required; refuse diag.
(e) A user target: allowed for fixed s only, PSD-checked.
